# 萬芳醫院藥事供應鏈 TASC 決策支援專家系統

以三能力供應鏈框架(TASC:敏捷性／適應性／一致性)為核心,整合序數優先法(OPA)、
Aczél–Alsina 加權評估(ALWAS)與模糊粗糙集(FRS)理論的藥事供應鏈決策支援工具。

## 🔗 線上系統
**https://maguro631023.github.io/wanfang-tasc-dss/**

掃碼分享頁(可手機開啟):`share.html`

## 內容
- `index.html` — 專家系統主程式(純前端,所有運算於瀏覽器完成,資料不外傳)
- `share.html` — QR code 分享頁,方便院內專家掃碼開啟
- 方法學依據:Sumrit & Katthamaruesee (2026), *Supply Chain Analytics* 13:100187

## 功能
1. **準則權重評估(OPA)** — 多專家就 12 項 TASC 準則評分,經 FRS 計算權重與排序
2. **績效指標評估(ALWAS)** — 多專家逐格評估準則對 11 項績效指標之影響,計算綜合分數排序
3. **分析結果** — 權重圖、排序表、Top-3
4. **策略建議** — 依結果自動產生萬芳藥事部門行動建議

> 本工具預設載入論文示範資料;專家評估以 E1–E7 代碼匿名輸入,不含病歷或醫療個資。
